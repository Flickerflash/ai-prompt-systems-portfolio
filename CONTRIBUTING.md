# Contributing to AI Prompt Systems Portfolio

## Governance and evidence boundary

This portfolio contains public examples of AI prompt systems and evaluation work. Project relationships, local rubrics, and governance terminology are descriptive and do not constitute external certification, accreditation, compliance, or production-readiness claims.

## What This Repo Contains

IP-safe, public examples of AI prompt systems and evaluation work. No client data. No proprietary constants.

- System prompt design patterns
- Role matrix and constraint gate examples
- A/B iteration frameworks
- Multi-agent workflow architecture (IP-safe)
- NIST-aligned audit templates

## Standards & Attribution

- **NIST AI RMF** — risk-management reference/alignment
- **DGAF** — related project-local governance/evaluation research
- **Paul-Elder Critical Thinking** — evaluation rubric/reference foundation

Project-local tiers, scores, confidence values, and benchmark labels are not external certifications. Any claimed result must be tied to the underlying evidence and methodology.

## IP Notice

This repo contains only IP-safe public examples. Core phi constants, frequency tuning tables, constraint algorithms, and inter-agent communication protocol internals are **excluded**.

## How to Contribute

1. Open an issue describing the prompt pattern or use case.
2. Fork and branch from `main`.
3. All examples must be IP-safe (no client data, no proprietary constants).
4. Submit PR with reproducible before/after quality evidence where applicable.
5. Do not present project-local scores, attestations, or tiers as independent certification without supporting evidence.
